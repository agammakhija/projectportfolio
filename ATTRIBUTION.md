## 🛠️ Customizations & Adaptations by Agam Makhija

The following customizations, systems, and content were created specifically for this portfolio:
1. **Developer Profile & Specialization**: Dedicated focus on **Python 3 Programming** and **AI Prompt Engineering** (Chain-of-Thought, System Instructions, Few-Shot Pattern Design, JSON Schema Enforcement).
2. **Academic Credentials**: Integrated credentials for Newton School of Technology (2026–2030, Ongoing B.Tech CSE AI/ML) and Prodigy Public School (2024–2026).
3. **Agam-DOS Terminal Interface**: Interactive command-line shell with the mandatory `agam` executable prefix, `agam man` manual, and the 5-point directory query and download system (`agam skills`, `agam education`, `agam portfolio`, `agam contacts`, `agam about`).
4. **Spider-Man Interactive Portfolio Embed**: Retro Internet Explorer browser window embedding Agam's live Spider-Man web application (`https://portfolio-swart-pi-47.vercel.app/`).
5. **Spider-Man Web Audio Synthesizer**: Algorithmic sound engine transcribing and synthesizing the 1967 Theme, 2002 Danny Elfman Theme, and 1994 Animated Theme in Winamp.
6. **Resident Evil Style 3D Sticky Note Inspection**: Real-time 3D raycast hover mechanic where the pinned monitor memo smoothly lifts off and zooms in for legible close-up reading with synthesized paper rustle sounds.
7. **Craft98 Voxel Sandbox**: In-hand voxel swinging animations, block debris particle explosions, creative flight, and hotbar selection.
